# 字体 / Fonts

界面用到的两套字体已按项目里出现的字子集化成 woff2，随仓库分发，离线和国内网络都能用。
缺字时（例如画界面里自己输入的新字）会回退到系统的宋体 / 苹方。

| 文件 | 字体 | 版权 | 许可 |
| --- | --- | --- | --- |
| `noto-serif-sc-400.woff2`、`noto-serif-sc-600.woff2` | Noto Serif SC（思源宋体） | Copyright 2012 Google Inc. | SIL Open Font License 1.1（见 OFL.txt） |
| `inter-400.woff2`、`inter-500.woff2`、`inter-600.woff2` | Inter | Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter) | SIL Open Font License 1.1 |

两者均为 SIL OFL 1.1，许可全文见 `OFL.txt`（Inter 使用同一份许可条款）。
